# Тестовый проект для CodeInspector

Этот проект создан для тестирования и демонстрации возможностей системы анализа кода CodeInspector.

## Структура проекта

```
test_project/
├── __init__.py          # Инициализация пакета
├── main.py              # Основной модуль с различными паттернами кода
├── utils.py             # Утилиты и вспомогательные классы
├── test_main.py         # Тестовые файлы
└── README.md            # Этот файл
```

## Особенности кода для тестирования

### main.py
- **TestConfig**: Dataclass для конфигурации
- **TestRunner**: Класс с методами для запуска тестов
- **complex_function_with_many_parameters**: Функция с 7 параметрами (должна вызвать предупреждение)
- **very_long_function**: Функция с 50+ строками (должна вызвать предупреждение)
- **VeryLargeClass**: Класс с 21 методом (должен вызвать предупреждение)

### utils.py
- **DataProcessor**: Класс для обработки данных
- **ConfigManager**: Менеджер конфигурации
- **save_to_file/load_from_file**: Функции для работы с файлами
- **validate_data**: Функция валидации

### test_main.py
- Тестовые классы для unittest
- Демонстрирует анализ тестовых файлов

## Запуск тестов

```bash
# Из корневой директории CodeInspector
python test_agents.py
```

## Ожидаемые результаты анализа

При анализе этого проекта CodeInspector должен обнаружить:

1. **Проблемы качества кода**:
   - Функция с слишком многими параметрами
   - Функция слишком длинная
   - Класс с слишком многими методами

2. **Структурные элементы**:
   - 3 класса
   - 8+ функций
   - Импорты и зависимости
   - Тестовые файлы

3. **Архитектурные паттерны**:
   - Разделение на модули
   - Использование dataclass
   - Паттерн менеджера конфигурации
